# Sources of the README pictures

`showcase.html` and `hero.html` are painted by Vitrail UI itself:
`cargo run --release --example shot -- ../../media/src/showcase.html out.png 1280 720 1.5` in `native/vitrail-ffi`.

- `world.jpg`: a game scene behind the panels.
- `AlegreyaSans-*.ttf`: Alegreya Sans by Huerta Tipográfica, SIL Open Font License 1.1.
